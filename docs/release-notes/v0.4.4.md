The pet plugin publishes on the family's aligned version. This release keeps a dragged position through a restart and records the pet intake round.

### Bug Fixes

- Pet: a dragged position now survives a restart (#2)
  - The settings mirror no longer hardcodes the `pet` namespace, so a rejected write under an aggregate install no longer drops the position
  - Mounting no longer overwrites the persisted position in `pet.json` with the schema defaults
